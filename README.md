Chess Game:

A simple and interactive **Chess Game** built using **HTML, CSS, and JavaScript**.
This project provides a playable chess board in the browser with a clean UI, theme support, and core chess gameplay functionality.


Project Overview:

This Chess Game is a web-based implementation of the classic chess board game. It allows users to play chess directly in the browser with an attractive interface and customizable themes. The project focuses on frontend development, game logic implementation, and user interaction using JavaScript.


Features:

* ♟️ Interactive chess board
* 👥 Two-player gameplay
* 🎨 Light and dark theme support
* 🖱️ Click-based piece movement
* ✅ Move validation using JavaScript
* 🔄 Dynamic board updates
* 🌐 Runs directly in the browser
* 📱 Clean and responsive UI design


Tech Stack:

* HTML5 – Structure of the chess board and webpage
* CSS3 – Styling, layout, and themes
* JavaScript – Game logic and interactivity

How to Run the Project:

1. Clone the repository

   ```bash
   git clone https://github.com/ruchirachowdary-1836/Chess-Game.git
   ```

2. Open the project folder

   ```bash
   cd Chess-Game
   ```

3. Run the project

   * Open `index.html` in your browser


How to Play:

1. Open the Chess Game in your browser.
2. Click on a chess piece to select it.
3. Click on the destination square to move the piece.
4. Continue taking turns between players.
5. Use the available theme styles for a better visual experience.


Themes:

This project includes support for multiple themes:

* Light Theme → Defined in `light.css`
* Dark Theme → Defined in `dark.css`

These themes improve the visual experience and allow users to switch between different board appearances.
